How should Path Planning use footing?

Footing is the learner’s self-reported starting point for each Skill in a Goal. It should help Helix choose where to begin and how deeply to teach—not decide what the learner has proven or silently remove a Skill.

Proposed rule

Keep each answer attached to its Skill or Subskill. Use it to adjust content selection, depth, and sequence. Remove a Skill only when the learner explicitly asks to remove it from the Goal.

3

What could go wrong?

These concerns need to be resolved before footing controls path construction.

One answer does not reveal intent

Advanced could mean “teach me harder material,” “verify me quickly,” or “leave this out.”

Self-report is not evidence

A learner can over- or underestimate their ability. Use a short check before skipping needed learning.

Learner level ≠ content level

A learner’s familiarity and a Course’s Beginner, Intermediate, or Advanced label describe different things.

Courses cover several Skills

One Advanced answer should not remove a Course that also covers material the learner still needs.

The current summary loses detail

Different answers are reduced to one starting point for the whole Goal before planning.

Starting point is not the destination

Target proficiency says where the path should end. Footing says where it should begin.

Wallet boundary

Answering this step should not silently create a self-claim. If offered, “Add this to my Skills Wallet” should be a separate explicit choice and distinct from verified proficiency.

Make the effect of each answer visible before the learner confirms the Goal.

Explain what will change

Your answers help Helix decide what to include, where your path begins, and where it can move faster.

After Advanced

Ask what the learner wants

Do not translate Advanced directly into exclusion.

Before Goal confirmation

Show the planning summary

Let the learner see and correct the consequence before the Goal is final.
